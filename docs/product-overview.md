# Crazy Noisy Quiz

## Visão do produto

O Crazy Noisy Quiz é uma arena multiplayer de quizzes para partidas entre amigos. Os jogadores entram em uma sala privada, escolhem categorias e competem respondendo perguntas em tempo real.

O produto terá foco em uma experiência simples, rápida e competitiva, com pontuação baseada em acerto e velocidade de resposta.

## Objetivos

- Criar uma experiência multiplayer divertida para grupos de amigos.
- Demonstrar competências de desenvolvimento mobile com Kotlin e Jetpack Compose.
- Demonstrar competências de backend com Java e Spring Boot.
- Trabalhar comunicação REST e eventos em tempo real via WebSocket.
- Construir uma base evolutiva para rankings, temporadas e equipes.

## Stack planejada

### Mobile

- Kotlin
- Jetpack Compose
- Arquitetura MVVM
- Coroutines e Flow
- Navigation Compose
- Retrofit
- Room para cache local, quando necessário

### Backend

- Java 21
- Spring Boot
- Spring Web
- Spring Security e JWT
- Spring Data JPA
- PostgreSQL
- Flyway
- WebSocket

### Qualidade e execução

- JUnit e Mockito
- Testcontainers
- Docker Compose
- OpenAPI/Swagger
- GitHub Actions
